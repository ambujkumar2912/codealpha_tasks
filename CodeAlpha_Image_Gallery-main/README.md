# Frame — Professional Image Gallery

A responsive real-world style image gallery created for the Code Alfa internship task.

## Features

- Professional editorial-style interface
- Responsive HTML and CSS layout
- JavaScript lightbox
- Previous and next image navigation
- Category filters
- Collection search
- Favorites system
- Hover effects and smooth transitions
- Keyboard navigation
- Mobile swipe navigation
- Responsive mobile and tablet layouts
- Semantic HTML and accessible controls

## Run

Open `index.html` in a modern browser.

The gallery images are loaded from Unsplash and require an internet connection.
