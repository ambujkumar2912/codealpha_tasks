# Code Alfa Calculator

A responsive calculator built with HTML, CSS and vanilla JavaScript.

## Features

- Addition, subtraction, multiplication and division
- Decimal calculations
- Percentage
- Clear and backspace controls
- Real-time display updates
- Keyboard support
- Division-by-zero handling
- Responsive layout
- Accessible button labels and focus states
- No frameworks or external JavaScript libraries

## Run

Open `index.html` in a browser.

## Keyboard

- `0-9` for numbers
- `.` for decimal
- `+ - * /` for operations
- `Enter` or `=` to calculate
- `Backspace` to delete
- `Esc` to clear
- `%` for percentage
